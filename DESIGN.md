# ClaerPlayer design

Mode: Operate / viewing. User approved dark screen with simple controls.

Black video canvas, charcoal header and transport, off-white primary text, muted but readable secondary text, restrained mint focus/active accent. Native Windows chrome, window resizing and keyboard conventions. Malgun Gothic is the native Korean UI face; no decorative display typography. Small custom vector transport icons use the same 1.8px stroke.

Main hierarchy: current filename, video, seek bar, playback controls. Secondary actions live in one menu. A collapsible queue is on the right. Empty/loading/error states use readable explanatory text and a file-open action. No account, feed, telemetry or promotional interface.

Native keyboard focus, accessible names and tooltips on every icon control. No animations that consume idle CPU. Quality controls describe rendering trade-offs without promising invented detail.
