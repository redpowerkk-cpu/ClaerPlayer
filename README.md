# ClaerPlayer 0.1.0

윈도우용 동영상·GIF 플레이어의 첫 시험판입니다. 어두운 화면, 간결한 조작부, mpv 기반 재생 엔진을 제공합니다.

## 설치와 실행

- `artifacts/ClaerPlayer-Setup-0.1.0-x64.exe`: 설치 프로그램. 현재 사용자 계정의 `%LOCALAPPDATA%\Programs\ClaerPlayer`에 설치합니다. 관리자 권한은 필요하지 않습니다.
- `artifacts/ClaerPlayer-Portable-0.1.0-x64.zip`: 압축을 모두 풀고 `ClaerPlayer.exe`를 실행합니다. DLL을 실행 파일과 같은 폴더에 두세요.
- Windows 10/11 x64 및 .NET Framework 4.8이 필요합니다. ARM64·32비트 전용 빌드는 포함하지 않습니다.
- 시작 메뉴와 선택적 바탕 화면 바로가기를 만듭니다. 기본 연결 프로그램은 변경하지 않습니다.
- 제거: Windows 설정의 설치된 앱에서 ClaerPlayer를 제거하거나 설치 폴더의 `Uninstall.exe`를 실행합니다. 설정과 시청 위치는 보존합니다.
- 개인용 시험판으로 코드 서명은 되어 있지 않습니다.

## 기능

파일 열기, 여러 파일 열기, 드래그 앤드롭, 재생목록, 순차 재생, 구간 이동, 배속, 볼륨·음소거, 파일 반복, GIF 자동 반복, 전체화면, 자막 추가·트랙 선택, 오디오 트랙 선택, 프레임 이동, PNG 캡처, 마지막 시청 위치 저장, 항상 위에 표시.

MP4, MKV, MOV, AVI, WMV, WebM, TS, GIF를 생성한 시험 파일로 검증했습니다. H.264, HEVC 10비트, VP9, AV1, MPEG-4, WMV2 디코딩을 확인했습니다. 그 외 형식은 포함된 mpv/FFmpeg의 지원 범위에 따르며 전수 검증하지 않았습니다. 모든 확장자의 모든 코덱 조합, DRM 보호 파일, 손상 파일의 재생을 보장하지 않습니다.

## 화질과 자원 사용

- **균형**: 원본 화면 비율을 유지하고 spline36 확대를 사용합니다. 추가 계조 보정과 프레임 보간은 끕니다.
- **고화질**: EWA Lanczos 확대, 색차 확대와 디밴딩을 적용합니다. 확대·색 띠 완화용이며 원본에 없는 디테일을 만들어 낸다는 뜻은 아닙니다. GPU 부하가 늘 수 있습니다.
- **저전력**: bilinear 확대와 보정 최소화를 사용합니다. 원본 디코딩 해상도를 강제로 낮추지 않습니다.

가능한 형식은 하드웨어 디코딩을 사용하고, 지원하지 않는 경우 소프트웨어로 처리합니다. 설정 메뉴에서 소프트웨어 디코딩으로 전환할 수 있습니다. D3D11과 gpu-next 출력을 사용합니다. 색 관리 및 출력 색 공간 자동 협상을 사용하지만 HDR 디스플레이의 실제 정확성은 이 버전에서 측정하지 않았습니다. 원본 해상도·압축·색 정보, 모니터 설정과 GPU가 최종 화질을 좌우합니다.

검증 PC에서 대기 중 약 56 MiB, 640×360 H.264 재생 후 일시정지 상태에서 약 219 MiB의 작업 집합 메모리를 관찰했습니다. 재생 후 수치는 화면 검사와 캡처를 포함한 시험 과정에서 측정했으며 일반적인 최대치나 다른 PC의 사용량을 의미하지 않습니다. 별도의 브라우저 실행 환경은 포함하지 않습니다. 코덱 엔진이 설치 용량 대부분을 차지합니다.

## 단축키

| 키 | 동작 |
| --- | --- |
| Ctrl+O | 파일 열기 |
| Space | 재생 / 일시정지 |
| ← / → | 5초 이동 |
| ↑ / ↓ | 볼륨 |
| M / R | 음소거 / 파일 반복 |
| F11 또는 F | 전체화면 |
| Esc | 전체화면 해제 |
| Ctrl+L | 재생목록 |
| Page Up / Page Down | 이전 / 다음 파일 |
| Ctrl+S / J | 자막 열기 / 자막 트랙 전환 |
| A | 오디오 트랙 전환 |
| Ctrl+P | 영상 캡처 저장 |
| . | 다음 프레임 |

시청 위치는 `%LOCALAPPDATA%\ClaerPlayer\settings.json`에 최대 100개 저장합니다. 메뉴의 ‘마지막 시청 위치 기억’을 끄면 저장된 위치를 지웁니다. 이 앱에는 계정·광고·분석 수집·자동 업데이트 기능이 없습니다.

## 검증

`tests/run.ps1`은 코덱·컨테이너·제어 시험을 실행하고 `tests/results/engine.json`에 결과를 생성합니다. `-Ui` 옵션을 추가하면 D3D11 출력, 파일 전환, GIF 반복, 영상 입력 경로의 단축키, 전체화면 복귀, 화면 크기, 오류 복구도 검사합니다. UI PNG는 앱 내부 렌더링과 GPU 출력 캡처이며, 실제 바탕 화면을 촬영한 이미지가 아닙니다. 생성된 시험 결과와 시청 기록은 Git에 포함하지 않습니다.

설치 파일의 압축 해제 결과와 배포 폴더를 해시로 비교합니다. 실제 Windows 사용자 계정으로의 설치·제거, HDR 측색, 4K/8K 장시간 재생, 저사양 PC, 다양한 화면 배율, 오디오 장치 전환과 특수 자막 형식은 추가 검증 대상입니다.

## 빌드

Windows의 .NET Framework C# 컴파일러를 사용합니다. 저장소를 내려받은 후 PowerShell에서 다음 순서로 실행합니다.

```powershell
.\fetch-deps.ps1
.\build.ps1
.\package.ps1
```

`package.ps1`은 `artifacts` 폴더에 설치 파일, 무설치 ZIP, 소스 ZIP과 SHA-256 검증값을 만듭니다. 다운로드 URL·SHA-256은 `dependency-lock.json`에 고정되어 있습니다. 대용량 재생 엔진과 설치 파일은 Git에 포함하지 않고 위 명령으로 준비합니다.

재생 검사를 실행하려면 PowerShell 7에서 다음 명령을 사용합니다. `-Ui` 검사는 플레이어 창을 표시하므로 필요한 경우에만 추가하세요.

```powershell
.\fetch-deps.ps1 -IncludeTestTools
.\tests\generate.ps1
.\tests\run.ps1
# 선택: .\tests\run.ps1 -Ui
```

테스트용 FFmpeg 도구는 플레이어 배포에 포함하지 않습니다.

ClaerPlayer 소스는 MIT 라이선스로 제공됩니다. 포함된 재생 엔진과 라이브러리는 별도 라이선스가 적용됩니다. `THIRD-PARTY-NOTICES.txt`와 `licenses`를 참조하세요. 이 패키지는 요청한 개인용 개발 결과물이며 공개 배포용 라이선스·코드 서명 검토를 마친 제품은 아닙니다.
